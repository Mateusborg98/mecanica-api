# Artefatos de descoberta do domínio

Esta pasta preserva os desenhos editáveis usados para entender o fluxo da
oficina antes das decisões de arquitetura.

- [Domain Storytelling](domain-storytelling.egn): atores, objetos de trabalho e
  interações do processo. Abra no Egon.io.
- [Event Storming](event-storming.excalidraw): comandos, eventos, políticas,
  regras e exceções do ciclo da ordem. Abra no Excalidraw.

Os artefatos destacam Cliente, Atendente, Mecânico e Sistema, além dos eventos
de solicitação, criação da OS, diagnóstico, orçamento, aprovação, consumo de
estoque, execução e finalização. Eles são complementares aos diagramas técnicos:

- [Arquitetura e sequências](../architecture.md)
- [Modelo relacional](../relational-model.md)
- [ADRs](../adr)
- [RFCs](../rfc)

Domain Storytelling e Event Storming descrevem o problema e o comportamento do
negócio. Os diagramas de componentes, sequência e ER descrevem a solução
técnica efetivamente implantada.
